# ChatBot

A small LangChain retrieval-augmented generation demo that stores text embeddings in ChromaDB, retrieves relevant context, and answers a question using an OpenAI chat model.

## What It Does

`Chatbot.py` performs the following steps:

1. Loads environment variables from a `.env` file.
2. Creates sample text documents about Playwright and Selenium.
3. Splits the text into chunks with LangChain.
4. Generates embeddings using OpenAI embeddings.
5. Stores the embedded documents in a local ChromaDB database.
6. Runs a similarity search for the query `What is Playwright?`.
7. Reloads the persisted ChromaDB database.
8. Uses the retrieved context with an OpenAI chat model to generate a final answer.

## Project Structure

```text
.

```

`chroma_db/` is the local persisted vector database created by the script.

## Requirements

- Python 3.10 or newer
- An OpenAI API key

Install the required packages:

```bash
pip install python-dotenv langchain-text-splitters langchain-openai langchain-community chromadb
```

## Environment Setup

Create a `.env` file in the project root:

```env
OPENAI_API_KEY=your_openai_api_key_here
```

## Run the Project

From the project directory, run:

```bash
python Chatbot.py
```

The script prints:

- Similarity search results from ChromaDB
- Retrieved documents
- A final answer generated by the chat model

## Notes

- The script currently uses sample in-memory documents.
- ChromaDB data is persisted in `./chroma_db`.
- The chat model is configured as `gpt-4o-mini` in `Chatbot.py`.
- Do not commit your `.env` file or API keys to version control.
